# 光储 Agent 的数据存储与时间口径

| 数据 | 写入与保存 | 页面怎样使用 |
| --- | --- | --- |
| 电站配置与实时快照 | 持有运行权的管理页推进仿真并上传。ECS 把电站配置、最新快照、运行租约和指令保存在 `/opt/solar-monitor/data/workspace.json`。 | APP 读取最新快照。快照里有近期采样。管理页关闭或失去运行权后，快照可能停更。 |
| 演练与提醒 | 同一文件保存每站演练状态、提醒记录和苏州遮挡事件。服务端按文件串行更新，先写临时文件，再原子替换。 | 过热演练从预设温升曲线开始；遮挡事件在读取时投影到苏州电站的功率、发电量与收益上。恢复场景后显示基础快照。 |
| 历史发电与收益 | `/opt/solar-monitor/data/history.json` 按电站和月份保存小时、日期汇总及批次截止时刻。历史续算脚本从上次截止时刻和末次 SOC 继续，按日期和小时合并。 | 管理面历史图、历史查询与历史月报使用已保存的模型数据。实时上传及场景触发均不追加历史日期。 |
| 个人提醒状态 | APP 在当前浏览器保存已展示的遮挡事件 ID 和提醒处理偏好。 | 重开同一事件会去重，管理面重新触发会生成新事件。同源标签页会收到刷新通知，跨设备通过接口轮询。 |

## 如何理解日期

管理面顶部使用当前所选电站时区，将仿真时钟换算为年月日。加速、暂停或跳时会影响这个日期。快照里的 `time.day` 表示年内序号，2026 年 12 月 13 日对应 347。快照的 `ts` 表示服务器最近接收上传的现实时间，用来判断同步是否停更。

查看某站的历史天数时，按该站实际保存的不同日期计数。批次截止当日可能只有部分时段；恰好在北京时间零点截止时，最后覆盖的是前一天。排查缺数时应比较电站的逐日记录、小时记录和批次截止时刻。
